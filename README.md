# Mobile Shop Management System

A responsive website for a mobile shop featuring product showcases, an interactive shopping cart, store information, and customer contact forms.

## Features

* **Homepage (`index.html`):** Modern layout featuring store highlights and featured products.
* **Product Catalog (`products.html`):** Browse available mobile phones and accessories.
* **Shopping Cart (`cart.html`):** Add and manage items for checkout.
* **About Us (`about.html`):** Insights into the store, counter setup, and store front.
* **Contact (`contact.html`):** Customer inquiry form and location details.
* **Responsive Design:** Custom CSS for optimal viewing across mobile, tablet, and desktop screens.

---

## Tech Stack

* **Frontend:** HTML5, CSS3, JavaScript (Vanilla ES6)
* **Assets:** Custom images (`store-front.jpg`, `store-counter.jpg`)
